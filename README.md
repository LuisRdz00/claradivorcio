# Clara Divorcio - Landing

Landing de Clara para trámite simple de divorcio.

**Dominio:** https://claradivorcio.vercel.app/

## Cómo actualizar (después de vincular con Vercel)

1. Edita `index.html`
2. En terminal:
```
git add .
git commit -m "actualización"
git push
```
Vercel despliega automático en 30 segundos.

## Estructura
- `index.html` - Landing completa (React via CDN, Pixel 530468854481617, ID Facebook 1056197757579024)
- `vercel.json` - Config Vercel
